## Muestra los comandos utilizados para crear, cambiar y fusionar las ramas:

Las ramas las creé en Gitbash y los pasos que use son: 

1. Entrar al main.
2. git checkout -b bootstrap para crear la rama de bootstrap.
3. git checkout -b tailwind para crear la rama de tailwind.
4. git push origin bootstrap para subir esta rama.
5. git push origin tailwind para subir esta rama.
